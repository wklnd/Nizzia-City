# Nizzia City

A browser-based game where you build your crime empire in a dynamic city. Manage businesses, commit crimes, trade stocks, battle rivals, and interact with NPCs in a persistent online world.

Heavily inspired by Torn.com. 

## Quick Start

### Prerequisites
- Node.js (v16+)
- MongoDB running locally or remote connection
- npm

### Setup

1. **Clone and install dependencies:**
   ```bash
   npm install
   cd frontend && npm install
   ```

2. **Set up environment variables:**
   Copy `example_env` to `.env` in the root directory and configure:
   ```
   MONGO_URI=mongodb://localhost:27017/nizziacity
   JWT_SECRET=your_secret_key_here
   NPC_LOG_MODE=dashboard    # or 'classic'
   LOG_COLOR_MODE=on
   FORCE_COLOR=1
   ```

3. **Start MongoDB:**
   ```bash
   mongod
   ```

4. **Start the backend** (in project root):
   ```bash
   npm start       # production server
   npm run dev     # with nodemon for development
   ```

5. **Start the frontend** (in new terminal, from `/frontend`):
   ```bash
   npm run dev     # Vite dev server
   ```

The frontend will run on `http://localhost:5173` by default.

## Tools

### Item Creator (`/tools/creation/itemCreator.html`)
Build game items with properties like weapons, armor, consumables, and loot caches. Open in browser and create/edit items that'll sync with the API. You can also edit items. 

### Pickpocket (`/tools/creation/pickpocketCreator.html`)
Test out the math behind pickpocketing NPCs. Input player stats and NPC stats to see success chances and potential loot.

### Player Tools (`/tools/player_tools/`)
- `addMoneyAllPlayers.js` - Add money to all players 
- `createPlayer.js` - Create a new player 
- `npcPlayerCreator.js` - Create npc players with random personalities. 

### Stocks (`/tools/stocks/`)
- `backfill.js` - Backfill stock price history (90 days are recommended)

There is other scripts and tools, but most are for import / export of data.

## Game Features 

- **Jobs & Income** - Earn money through legitimate work
- **Crimes** - Risky activities with higher payouts
- **Businesses** - Own and manage profitable ventures, both legal and "illegal"
- **Stock Market** - Trade stocks with price volatility
- **Real Estate** - Buy properties
- **Inventory System** - Collect items, weapons, and consumables
- **Cartels** - Form groups and take territory
- **Grow operations** - Invest in growing the special green plant for profit

## Development Notes

- Frontend will proxy API requests to `http://localhost:5050`
